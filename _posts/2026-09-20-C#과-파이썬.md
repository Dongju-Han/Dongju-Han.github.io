# C#과 파이썬

C#과 파이썬 비교하며 공부한 내용

## 변수 선언

```python
num1 = 5
num2 = 3
result = num1 + num2
print(result)
```

```C#
using System;

class MainClass
    {
        public static void Main (string[] args)
            {
                int result, num1, num2;
                num1 = 5;
                num2 = 3;
                result = num1 + num2;
                Console.WriteLine(result);
            }
    }
```

파이썬은 변수를 미리 선언하지 않아도 된다. 하지만 C#은 선언을 하고 사용해야 한다.
파이썬을 먼저 배우고 써온 사람으로서, 현재까진 이 점이 파이썬과 C#의 가장 큰 차이로 느껴진다.
